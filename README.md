# CATHERINE
You dress up a fine lady named catherine!

No AI was used in the making of this game!
Most of the time making this game went to learning how to program a website

To run the game you need to download the file and run it in a browser. You need an internet connection to run it!
The code was written using an application named VsCode and the art using an application named Krita.

Click the buttons at the top to cycle through different tops, makeup looks and accessories.
